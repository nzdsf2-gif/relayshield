## MS-3 and MS-4

**MS-3, Security Copilot agent in Security Store, is the higher-value one.** It puts RelayShield
inside Microsoft's own security surface, in front of SOC teams that already hold budget and a
procurement path. Same buyer as Sentinel and QRadar, so it reinforces the enterprise motion rather
than scattering it.

**MS-4, Power Platform certification, is broader but shallower.** The connector becomes discoverable
to every Power Automate user: more reach, less qualified. **Irreversible catch flagged in the prep
doc: "The Premium tier can't be removed or changed at any time."** Decide the tier deliberately,
because it cannot be walked back.

**Flywheel fit, and the argument for doing both:** same shape as Ansible Galaxy. The connector and
the agent are both useless without an API key, so discovery converts to signup structurally rather
than by persuasion. There is no free tier to get stuck in.
