## THE THREE LESSONS FROM THIS SESSION, IN ONE LINE EACH

All three are written up in full in `CLAUDE.md`; these are the pointers.

1. **An endpoint is not shipped until the preflight answers, and curl cannot tell you.** The
   watchlist Lambda returned no CORS headers at all, so every terminal test would have passed on an
   endpoint that was dead in the only client that uses it.
2. **After any AWS create, ask what the NEXT call assumes about it.** `create-role`,
   `create-function` and `create-deployment` all return before the thing is usable. Three instances
   in one script, in one session.
3. **A lesson recorded in one file is not a lesson the next file learns.** The propagation race was
   already solved, with the diagnosis written out, inside `create_mpp_settlement_lambda.sh` on
   2026-09-05. A script written four days later hit it anyway. The fix was a shared file, not a
   fourth comment.
