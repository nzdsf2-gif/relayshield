RelayShield Consumption Security API Bundles

SaaS, delivered as an HTTPS API and as an MCP endpoint. The API, the data and the billing run on AWS in one region (us-east-1) and one account.
Single AWS account  ·  us-east-1
1 · Subscribe and fulfill
AWS MarketplaceBuyer subscribes and is redirected to our fulfillment URL with the registration token
↓ HTTPS
Amazon API GatewayREST API behind api.relayshield.net, TLS
↓
AWS Lambda, fulfillmentCalls ResolveCustomer and GetEntitlements, then issues the customer's API key
↓
Amazon DynamoDBKey record: customer identifier, product code, entitlement state. On-demand capacity
↓
Amazon SESDelivers the key to the buyer's registered address
2 · Serve a call
Customer application or AI agentHTTPS with the issued API key, directly, or through the MCP endpoint at /mcp
↓ HTTPS
Amazon API Gateway/mcp: an AWS Lambda MCP server that forwards each tool call. /v1/metered/: MCP and agent screening, identity risk, tech-stack CVE, LLM credential exposure
↓
AWS Lambda, API functionsAuthenticate the key, confirm the entitlement, run the check
↓ ↑
Amazon DynamoDBIndicator corpus, key records, usage counters
↓
AWS Secrets ManagerService credentials, read at runtime
3 · Meter, collect, observe
AWS Marketplace MeteringBatchMeterUsage is called by the API functions at the point of use, once per call, against the usage dimension
 
AWS Marketplace EntitlementGetEntitlements confirms the monthly entitlement during fulfillment
 
Amazon EventBridge → AWS Lambda collectorsScheduled functions refresh the indicator corpus in DynamoDB from public feeds and monitored sources
↓
Amazon CloudWatchLogs from every function. Error alarms on selected functions
Outside AWS  ·  shown so the boundary is explicit
Cloudflare Workers, public web pagesMarketing, documentation and pricing pages. API traffic does not pass through them
Public data sourcesRead by the scheduled collectors to build the indicator corpus. No customer query data is sent to them, and no customer call reaches them
Compute is AWS Lambda. DynamoDB tables use on-demand capacity. Metered calls are authenticated by API key.
