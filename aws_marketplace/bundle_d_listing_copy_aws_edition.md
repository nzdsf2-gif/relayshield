## Long description

Bundle D: Agentic Attack Surface is built for the emerging risk of AI-agent-driven attacks. It includes MCP registry risk scoring (detecting typosquatted AI agent tool servers and domains already known to be malicious), prompt-injection breach correlation (surfacing exposed sessions tied to prompt-injection attacks via infostealer log analysis), agent-framework CVE targeting risk (CVE exposure scoped to your declared agent stack, LangChain, AutoGPT, CrewAI, and similar), bulk per-agent identity risk scoring across up to 10 domains and 5 agents each, purpose-built for AI governance programs and MSP client sweeps, and LLM credential exposure detection to detect exposed LLM/AI provider API keys (OpenAI, Anthropic, Google, Groq, xAI, Replicate) in criminal stealer logs.

The checks are delivered as an MCP server, so an AI agent can call them directly as part of its own reasoning, and as REST endpoints for existing security pipelines.

Every score is computed from RelayShield's own continuously collected corpus: monitored criminal Telegram marketplaces, infostealer log dumps, and public indicator feeds. The queries you send are not forwarded to outside data providers, and every response names any signal it did not run, so a missing signal is never mistaken for a clean result. We deliberately do not quote a corpus headline here. A total indicator count is dominated by public feeds that most buyers already ingest, and it is out of date the week it is published; what matters is the exclusive fraction, which we report per capability on request.

Billing note: the monthly minimum commitment applies whether or not you call a given security function that month, and per-Unit charges apply only to the functions you actually call above the included baseline. Your API key is issued automatically by email when your AWS Marketplace subscription activates, with full usage instructions included. All access is provisioned and billed through AWS Marketplace.
