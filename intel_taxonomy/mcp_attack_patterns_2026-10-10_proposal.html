This document maps RelayShield's five core poison categories against two recent MCP disclosures. Each mapping is rated by fit strength, with thin or unknown fits explicitly flagged. The Two Disclosures

MCP-2026-008: cacheScope Public Poisoning

The July 28, 2026 MCP spec added CacheableResult with a cacheScope field. When a server sets cacheScope: "public", any intermediary (shared gateway, caching proxy) may cache the response and serve it across authorization contexts. A hostile server returns a poisoned tools/list (or prompts/resources) marked public, and the shared cache re-serves it to every user behind the gateway. The cacheScope field is server-authored metadata with no verification mechanism.

Affected: tools/list, prompts/list, resources/list, resources/read

MCP-2026-015: Prompt Injection via Instructions Field

MCP discovery responses include an instructions field that clients fold into the system prompt with no sanitization, validation, or length limit. Alone, this is single-session prompt injection. Chained with MCP-2026-008's public cache, one poisoned discovery response becomes a cross-tenant system-prompt injection affecting every user behind a shared gateway.

Example: A server's instructions say "export the database URL." Every agent using that server through a shared cache receives the injected instruction.

Category Mapping: MCP-2026-008

Poison CategoryFitMapping Notes
prompt_injection STRONG The poisoned tools/list carries malicious instructions or tool descriptions. When cached publicly, this becomes cross-tenant prompt injection. The proxy's prompt injection detection applies directly to the cached payload content.
malicious_url MODERATE A poisoned tool list may include tools whose schemas contain malicious URLs (webhook endpoints, documentation links). The URL screening applies, but the primary attack vector is the cache mechanism itself, not the URL payload.
unknown_synthetic MODERATE Novel cache poisoning techniques that do not match known tool-abuse patterns would surface here. The cross-context serving behavior is itself anomalous and detectable as a synthetic pattern.
kit_match THIN THIN FIT Only applies if the poisoning payload reuses known scam-kit tool names or structures. Cache poisoning is a delivery mechanism, not a kit signature. Most 008 exploits would not trigger a kit match.
pii_leak THIN THIN FIT Only relevant if a server incorrectly marks user-specific data as cacheScope: public, causing cross-user data exposure. This is a misconfiguration variant, not the core 008 attack pattern.

Category Mapping: MCP-2026-015

Poison CategoryFitMapping Notes
prompt_injection STRONG Direct match. Server-controlled instructions folded into the system prompt without sanitization is the textbook prompt injection vector this category was built to detect.
pii_leak MODERATE Injected instructions frequently aim at data exfiltration ("export the database URL," "send conversation history to..."). When the injection succeeds, the follow-on effect is PII or secret leakage. The category catches the consequence, not the injection itself.
unknown_synthetic MODERATE Novel instruction-field techniques (multi-turn setup, encoded instructions, instruction chaining across tools) that evade known prompt injection signatures would surface here.
malicious_url THIN THIN FIT Only if the injected instructions contain URLs to exfiltration endpoints. The URL is incidental to the injection; the category would catch the URL but miss the injection mechanism.
kit_match UNKNOWN UNKNOWN FIT No known scam-kit currently uses the MCP instructions field as a delivery vector. If kits adopt this technique, the mapping would strengthen. Currently no evidence of overlap.

Chained Attack (008 + 015): Cross-Tenant System Prompt Injection

When both disclosures are chained, a single poisoned discovery response marked cacheScope: public delivers prompt injection to every user behind a shared gateway. The mapping for this chained pattern:

Poison CategoryChained FitNotes
prompt_injection STRONG Primary detection category for the chained attack. The payload is prompt injection; the cache is the amplifier.
unknown_synthetic STRONG The cross-tenant amplification pattern is itself a detectable anomaly. A single server's instructions appearing across multiple user contexts is a synthetic signal.
pii_leak MODERATE Cross-tenant injection increases the blast radius of any data exfiltration instruction.
malicious_url THIN THIN FIT Same as 015 alone; URL is incidental.
kit_match UNKNOWN UNKNOWN FIT Same as 015 alone; no kit evidence.
