How to read this

Every tool call passes through the proxy in layers. Phase 4 policy rules run first (deterministic allow/deny). Then the proxy screens arguments and responses against the TI corpus. Phase 3 behavioral baselining watches for anomalous agents and attack chains. Every decision gets a signed verdict. ALLOW means the call proceeded. BLOCK means the call or response was stopped. QUARANTINE means the server earned three strikes and is now fail-closed.
