How to read this

Every tool call passes through the proxy. The proxy screens arguments and responses against the TI corpus, then issues a signed verdict. ALLOW means the call proceeded. BLOCK means the call or response was stopped. QUARANTINE means the server earned three strikes and is now fail-closed.
